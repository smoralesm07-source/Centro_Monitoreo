CENTRO DE MONITOREO ESTRATÉGICO UAF

1. Abre index.html en Chrome o Edge para revisar el prototipo.
2. Los botones abren los monitores actuales:
   - https://smoralesm07-source.github.io/Monitor/
   - https://smoralesm07-source.github.io/Monitor-Legislativo/
3. La portada intenta consultar automáticamente:
   - Monitor/resumen.json
   - Monitor-Legislativo/resumen.json
4. Mientras esos archivos no existan, utiliza cifras demostrativas y mantiene todos los accesos operativos.
5. Para publicarlo en GitHub Pages, crea un repositorio, por ejemplo Centro-Monitoreo, y sube index.html a la raíz.
